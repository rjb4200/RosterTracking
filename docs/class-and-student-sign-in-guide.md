# Roster Command quick guide

## Create a class (staff)

1. Go to **Staff login** and sign in with your assigned username and password.
2. Open **Classes**, then select **New class**.
3. Choose where the class is reported (for example, Fire, KBEMS, or MTU). Complete any fields that appear for the selected destination.
4. Enter the class details: name, delivery method, training site (unless online), host agency, date/time, duration, and lead instructor.
5. Select **Next** through the remaining steps, review the information, then select **Create & open**.
6. On the class page, open **Student access**. Display the QR code or share the sign-in link. If you enabled a four-digit PIN, share that PIN with the class.

## Student sign-in instructions

1. Scan the QR code or open the class sign-in link provided by your instructor.
2. If a PIN is requested, enter the four-digit class PIN.
3. Enter the mobile phone number on your student profile and select **Continue**.
4. If your profile is found, confirm that it is you. Confirm or update any requested information, choose the agency you represent today, then select **Confirm & Sign In**.
5. If you are new, enter your name, phone number, email, requested credentials, and agency to create your profile, then complete the final confirmation.
6. If your phone number changed, choose **My phone number changed** and verify using your previous phone number and profile email.
7. If you are attending as a guest, choose **Sign in as a guest**. Guest attendance is saved only for this class and does not create a student profile.
8. Wait for the confirmation message: **You're signed in**. Your attendance is recorded; do not submit again.

Completion certificates are emailed to the address shown during sign-in. Ask the instructor for help if the class link or PIN is unavailable.
