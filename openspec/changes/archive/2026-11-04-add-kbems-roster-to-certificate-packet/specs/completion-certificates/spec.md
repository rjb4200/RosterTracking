# Spec Delta

## MODIFIED Requirements

### Requirement: The admin batch pairs a student list with certificates

The system SHALL produce, for a finalized EMS class, one PDF packet that begins with the KBEMS-E16 roster pages, followed by one certificate page per active participant, and ends with a generated cover page listing the class and each active participant's name, represented agency, and credited hours. The roster and cover SHALL include every active participant exactly once across their pages. The cover page SHALL state the class's scheduled hours in its header together with the class, completion date, and participant count, and SHALL render the same class-hours value the certificate pages carry. The cover page SHALL paginate rather than omit participants. The cover page SHALL be generated by the system and SHALL NOT reproduce a retired state form other than the approved KBEMS-E16 roster.

#### Scenario: Produce the batch
- **WHEN** authorized staff request the certificate packet for a finalized EMS class
- **THEN** the PDF begins with the E16 roster pages, continues with one certificate page per active participant, and ends with the cover page

#### Scenario: List every active participant
- **WHEN** a finalized revision has several active participants
- **THEN** the E16 roster and the cover each list every active participant, and the packet contains a certificate for each

#### Scenario: Exclude a removed participant
- **WHEN** a participant's attendance was removed before finalization
- **THEN** the roster, cover, and certificates omit that participant

#### Scenario: State the class hours in the cover header
- **WHEN** authorized staff request the certificate packet for a finalized class
- **THEN** the cover header states the class's scheduled hours alongside the class, completion date, and participant count

#### Scenario: Match the certificates when participant credits differ
- **WHEN** a class's participants are credited hours that differ from the class's scheduled hours
- **THEN** the cover header states the class's scheduled hours, matching the certificates, while each participant's row keeps that participant's credited hours

#### Scenario: Paginate a large cover
- **WHEN** a finalized revision has more participants than one cover page supports
- **THEN** the cover spans as many pages as needed and lists every participant exactly once

## ADDED Requirements

### Requirement: The roster is not attached to individual certificate emails
The system SHALL NOT include the KBEMS-E16 roster in a participant's individual certificate email. An individual certificate email SHALL contain only that participant's certificate.

#### Scenario: Email one participant's certificate
- **WHEN** the system sends a participant their certificate at finalization or on resend
- **THEN** the attachment contains only that participant's certificate and no roster pages
