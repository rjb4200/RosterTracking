## MODIFIED Requirements

### Requirement: The admin batch pairs a student list with certificates

The system SHALL produce, for a finalized EMS class, one PDF that begins with a student-list cover page listing the class and each active participant's name, represented agency, and credited hours, followed by one certificate page per active participant. The cover page SHALL state the class's scheduled hours in its header together with the class, the completion date, and the participant count, and SHALL render the same class-hours value the certificate pages carry. The cover page SHALL be generated by the system and SHALL NOT reproduce a retired state form.

#### Scenario: Produce the batch
- **WHEN** authorized staff request the certificate batch for a finalized EMS class
- **THEN** the system returns one PDF whose first page lists the participants and whose remaining pages are one certificate per active participant

#### Scenario: List every active participant
- **WHEN** a finalized revision has several active participants
- **THEN** the cover lists each active participant and the PDF contains a certificate for each

#### Scenario: Exclude a removed participant
- **WHEN** a participant's attendance was removed before finalization
- **THEN** the cover and certificates omit that participant

#### Scenario: State the class hours in the cover header
- **WHEN** authorized staff request the certificate batch for a finalized class
- **THEN** the cover header states the class's scheduled hours alongside the class, completion date, and participant count

#### Scenario: Match the certificates when participant credits differ
- **WHEN** a class's participants are credited hours that differ from the class's scheduled hours
- **THEN** the cover header states the class's scheduled hours, matching the certificates, while each participant's row keeps that participant's credited hours
