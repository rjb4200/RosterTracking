## REMOVED Requirements

### Requirement: MTU usage is editable at any time
**Reason**: The review screen no longer maintains an independent operational MTU editor beside the finalize step. MTU usage is recorded when the class is set up and confirmed once at finalization, so it is no longer editable at any time after the class is signed without reopening.
**Migration**: Set or correct MTU usage before finalizing — during class creation, on the class edit screen, or in the finalize confirmation step. To change MTU usage after finalization, reopen the class.
